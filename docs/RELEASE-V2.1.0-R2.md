# ClearMeeting Server V2.1.0 R2

独立服务器仓库首次发布。完整标识 `clearmeeting-server-v2.1.0-daily-message-r2`，API保持 `luoye-device-api/2`。

## 本版内容

- 对齐录音卡V2.1.0省电查阅版的每日寄语和唤醒待办同步。
- 寄语按账号、显示日期缓存，每日最多一次后台AI尝试；接口不等待模型。
- 待办版本不变时，携带include_daily_message=1仍返回完整快照。
- 短寄语关闭思考模式，避免token预算耗尽；会议纪要模型配置不变。
- 包含既有离线队列、失败处理、手动模板纪要、人员确认及完整Word导出改进。
- 清理部署示例中的私人地址，更新版本校验、离线启动profile及重试上限示例。

## 下载与升级

附件ZIP为完整干净源码（含网页源代码），不是仅有三个文件的增量补丁。
不含密钥、数据库、音频、模型缓存或编译产物；部署时构建网页、安装依赖并下载模型。
`SHA256SUMS.txt`用于校验附件，包内清单记录源码提交和文件哈希。

请按[部署教程](https://github.com/kateya-luo/clearmeeting-server/blob/main/docs/DEPLOYMENT.md)先备份再升级，不覆盖既有数据和密钥。
固件和硬件入口：[落叶总项目](https://github.com/kateya-luo/luoye)。

## 验证与边界

- 后端回归163项通过。
- 网页测试49项通过。
- 线上V2.1.0 R2健康检查及寄语真实模型调用已验证。
- 本次发布不改变正在运行的服务器，不发布新固件。
- 工程版本仍需各部署环境的长录音、弱网、设备唤醒及模型下载验收；不承诺所有音频均能成功识别。
- AI模型和第三方依赖适用各自的服务条款/许可证。
